# Deploy Registry

Un archivo por deploy. Naming: `deploy_NNN_YYYYMMDD.md`

Cada registro captura:
- qué se deployó y por qué
- configuración exacta del sistema en ese momento
- estado del paper engine al momento del deploy
- issues conocidos
- observaciones al cerrar el período

Al iniciar un nuevo deploy, revisar el registro anterior para entender el contexto.
