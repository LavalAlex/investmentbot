## Infraestructura

### Comando de deploy
```bash
docker build -t gcr.io/PROJECT_ID/investmentbot .
docker push gcr.io/PROJECT_ID/investmentbot

gcloud compute instances create-with-container investmentbot \
  --zone=europe-west1-b \
  --machine-type=e2-micro \
  --container-image=gcr.io/PROJECT_ID/investmentbot \
  --container-env=BINANCE_API_KEY=***,BINANCE_SECRET=*** \
  --container-mount-host-path=mount-path=/app/logs,host-path=/var/investmentbot/logs \
  --container-mount-host-path=mount-path=/app/paper_state.json,host-path=/var/investmentbot/paper_state.json \
  --tags=http-server
```

### Endpoints disponibles
| Endpoint | Descripción |
|---|---|
| `GET /health` | Estado del sistema, conexión Binance, monitor running |
| `GET /status` | Equity, trades, PF, posiciones abiertas |
| `GET /logs/latest` | Último scan block |
| `GET /logs/download?date=YYYY-MM-DD` | Log de un día |
| `GET /logs/download?from=...&to=...` | Rango de días (zip) |
| `GET /docs` | Documentación interactiva FastAPI |
