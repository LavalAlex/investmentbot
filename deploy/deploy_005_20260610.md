# Deploy 005 — V3 Daily Breakout (reemplaza pullback)

**Fecha:** 2026-06-10
**Estrategia anterior:** Pullback EXP017-B (BTC) + EXP016A (ETH)
**Estrategia nueva:** Daily Breakout 10d vol≥1.5× ATR×1.5 RR=2

---

## Motivación

El pullback tiene PF=0.896 sobre 5 años (pierde dinero con fees). El Daily Breakout
tiene PF=1.735 (BTC) y PF=1.711 (ETH) en IS 5 años, validado con OOS 730d y
walk-forward 3 ventanas. Fees 160× menores ($50 vs $8,168 en 730d).

Ver sesiones de validación:
- `experiments/exp_session_2026_06_09_breakout_analysis.md`
- `experiments/exp_session_2026_06_10_breakout_architecture.md`
- `experiments/exp_session_2026_06_10_combined_strategy.md`

## Qué cambia

### `api/main.py`
- Import: `paper_monitor` → `paper_engine_breakout` + `core.strategy_breakout.RISK_PCT`
- `STATE_FILES`: `btc_state.json` / `eth_state.json` → `btc_breakout_state.json` / `eth_breakout_state.json`
- `_LOG_PREFIX_MAP`: `btc` → `btc_breakout`, `eth` → `eth_breakout`
- Monitor thread: siempre usa `PaperEngine` (sin LiveEngine branch para breakout)
- `run_scan()` call: sin `last_candle_ts` ni `live=LIVE_MODE` (breakout no los usa)
- Log file lookups actualizados en `/status`, `/health`, `/logs/latest`, `/logs/download`

### `Dockerfile`
- `COPY`: `paper_monitor.py` → `paper_engine_breakout.py`
- CMD sin cambios: `uvicorn api.main:app` (el motor corre en background thread)

### Archivado (no borrado)
- `paper_monitor.py` — queda en git, no se copia al container
